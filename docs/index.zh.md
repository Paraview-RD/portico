# Portico

这是你正在运行的这个 Portico 的文档。它随二进制一起构建，所以它描述的是**这个
版本**，而不是最新版本——如果眼前的界面和眼前的文档对不上，那件事本身值得报告。

## 从这里开始

**[访问指南](access-guide.md)** —— 入口地址、凭据从哪来、两种角色各自到底能做
什么。写的是人实际走的流程，不是界面清单。先读这一份。

## 把账号接进来

两个方向，而这个区别比听上去重要：

- **[目录对接](ldap.md)** —— Portico 主动连接你的 Active Directory 或
  OpenLDAP，把账号拉过来。**由 Portico 发起，并且 Portico 要保管一份凭据。**
- **[目录供给](scim.md)** —— 你的目录通过 SCIM 2.0 主动把账号推进来。
  **由目录发起，凭据由目录保管。**

如果你的目录能推，优先用推：这样这里根本不需要存任何服务账号的信息。

## 让应用接进来

**[单点登录](federation.md)** —— OAuth 2.1、OpenID Connect、SAML 2.0 和 CAS，
并附一张表说明**每种协议下"撤销"到底能撤到哪里**。这一份值得在部署之前读，而不
是等到有人来问"为什么已经退出登录的人还在某个应用里"。

**[事件订阅](webhooks.md)** —— 账号、机构、用户组发生变化时推送一个带签名的
POST，含订阅方应当实现的验签方法。
